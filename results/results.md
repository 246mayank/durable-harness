# Results

Generated by `python -m chaos.bench --scenarios 500 --seed 0` at commit `0cdb9e0`. Journal durability: `synchronous=FULL`.
Do not edit by hand.

Each of the **500 seeded scenarios** fixes a fault stream (429 / 5xx-before-commit / commit-then-504, each p in [0, 0.15]), a crash schedule (0-3 in-process crashes at named crash points) and a planner temperature (0, 0.3 or 0.7). Every scenario is replayed against every config on a fresh simulated platform. All numbers are counted from the platform's own audit log, not from what the agent believes.

## Configs

- `naive`: no replay, no keys, no retries: errors go back to the planner
- `naive_retry`: naive + 5 blind retries
- `keys_only`: naive_retry + idempotency keys hashed from the arguments
- `harness`: journal replay + positional keys + effect-class recovery
- `harness_cas`: harness + conditional writes (`expected_total`) on allocations

Escalations are resolved by an operator that reads the platform's audit log, which models a person checking the dashboard. Each one is a human interruption: a cost, not a free fix.
