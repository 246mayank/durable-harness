# Results

Generated by `python -m chaos.bench --scenarios 500 --zombies 200 --seed 0` at commit `9deec27`. Journal durability: `synchronous=FULL`.
Do not edit by hand.

Each of the **500 seeded scenarios** fixes a fault stream (429 / 5xx-before-commit / commit-then-504 / delayed delivery, each p in [0, 0.15]), a crash schedule (0-3 in-process crashes at named crash points) and a planner temperature (0, 0.3 or 0.7). Every scenario is replayed against every config on a fresh simulated platform. All numbers are counted from the platform's own audit log, after every request still in flight has landed or been dropped, not from what the agent believes.

### Zombie incarnations: fencing and deadlines on and off

200 scenarios with the same fault mix and no crashes. Instead, the first incarnation hangs at a random hook point; a replacement takes the run over and finishes it; then the hung one wakes up and carries on. `before_send` (after the fence check, before the request leaves) is among the hang points.

Fencing stops a woken incarnation from journaling or sending again. Deadlines cover the one send it may already have been about to make: by the time it goes out, its deadline has passed, because the new owner waited it out before acting on a negative lookup or an operator's check.

## Configs

- `naive`: no replay, no keys, no retries: errors go back to the planner
- `naive_retry`: naive + 5 blind retries
- `keys_only`: naive_retry + idempotency keys hashed from the arguments
- `harness`: journal replay + positional keys + effect-class recovery + deadlines + fencing
- `harness_cas`: harness + conditional writes (`expected_total`) on allocations
- `harness_nodeadline`: harness without deadlines: lookups and the operator don't wait
- `harness_cas_nodeadline`: harness_cas without deadlines
- `harness_nofence`: harness without fencing: a woken incarnation can keep journaling
- `harness_neither`: harness without fencing or deadlines

Escalations are resolved by an operator that waits out the call's deadline, lets any request still in flight land, and then reads the platform's audit log: a person checking the dashboard. Each one is a human interruption: a cost, not a free fix.
