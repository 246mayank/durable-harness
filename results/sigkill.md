# Hard-kill results

Generated by `python -m chaos.sigkill --scenarios 40 --seed 0` at commit `0cdb9e0`. Do not edit by hand.

The agent and the simulated platform run as separate OS processes. Each agent incarnation that is scheduled to die is killed from outside (`Popen.kill`: SIGKILL on POSIX, TerminateProcess on Windows) after a uniform random delay between 0 and that config's own clean-run duration (measured first: `naive_retry` 72 ms, `keys_only` 84 ms, `harness` 204 ms, `harness_cas` 192 ms), so kills land at a uniformly random point of the run. Kill timing is wall-clock, so these numbers are not bit-for-bit reproducible. Faults and temperatures come from the same seeded scenarios as results.md.
